# 📚 Smart Study Tracker

A modern productivity-focused study management application built using **Python**, **Streamlit**, and **MongoDB**.

Smart Study Tracker helps students organize subjects, manage study topics, track learning progress, monitor recent activity, and maintain a structured learning workflow.

---

# 🚀 Features

## 🔐 Authentication System

* User Sign Up & Sign In
* Forgot Password
* Change Password
* Delete Account
* Session Management

---

# 📘 Subject Management

* Add Subjects
* Delete Subjects
* Subject-wise Progress Tracking
* Subject Analytics

---

# 📖 Topic / Chapter Management

* Add Topics
* Delete Topics
* Mark Topics Complete
* Undo Completed Topics
* Progress Tracking

# ⚡ Installation

## Clone Repository

```bash
git clone https://github.com/your-username/Python-OJT2.git
```

---

## Move Into Project

```bash
cd "Smart Study Tracker"
```

---

## Install Dependencies

```bash
pip install -r requirements.txt
```

---

## Run Application

```bash
streamlit run App.py
```
